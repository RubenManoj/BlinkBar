# Installing BlinkBar

BlinkBar is distributed as a zipped macOS app bundle.

## Install

1. Unzip `BlinkBar-1.0.zip`.
2. Move `BlinkBar.app` to `/Applications`.
3. Open `BlinkBar.app`.

Because this local build is ad-hoc signed and not notarized by Apple, macOS may block the first launch.

If that happens:

1. Open **System Settings > Privacy & Security**.
2. Find the message about `BlinkBar`.
3. Click **Open Anyway**.

## Notifications

For macOS notification mode, enable:

```text
System Settings > Notifications > BlinkBar > Allow Notifications
```

Full-screen overlay and popup modes do not require notification permission.
